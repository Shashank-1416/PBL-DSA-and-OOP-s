Campus recruitment involves managing applicants across multiple stages — Applied, Screening, Interview, and Offer — for several companies simultaneously. Manual tracking makes it difficult to guarantee fairness (processing applicants in the order they arrive) and to safely reverse recruiter mistakes, such as accidentally advancing or rejecting the wrong applicant.

This project addresses these problems by building a C++ console-based Multi-Stage Job Application Tracker. Applicants move through recruitment stages using Queues, ensuring First-In-First-Out fairness at each stage. A Linked List stores each applicant's variable-length event history and also backs the queue implementation itself, enabling flexible mid-queue removal and re-insertion required during rollback. A Stack maintains a chronological log of recruiter actions, supporting reliable Undo functionality that reverses the most recent action and correctly restores applicants to their prior stage.

The system is designed using Object-Oriented Programming principles: encapsulation (private applicant/company data with controlled access), inheritance (Screening, Interview, and Offer derived from a common PipelineStage base class), polymorphism (overridden processApplicant() behavior per stage), and abstraction (simple operations like advanceStage() hiding underlying queue/stack logic). File handling via C++'s fstream provides state persistence across sessions, an append-only audit log, and generated reports summarizing applicants per stage and rollback activity.

The proposed outcome is a fully functional, demo-ready application that manages multiple companies' independent recruitment pipelines while reliably supporting fairness, rollback, and persistent record-keeping — directly demonstrating practical mastery of Queue, Linked List, Stack, and OOP concepts within a single, cohesive C++ system.
